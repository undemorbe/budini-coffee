# Будини Coffee · лендинг кофейни

Vite + Vue 3 + Vue Router. Цвета взяты с вывески «Будини»: неоновая мята `#66D4BE` / `#3ABBB0`
на ночном чёрном `#07090C`. Шрифты: Unbounded (заголовки) и Onest (текст).

## Запуск

```bash
npm install
npm run dev      # разработка
npm run build    # production-сборка в dist/
npm run preview  # просмотр сборки
```

## Деплой на GitHub Pages

`.github/workflows/deploy.yml`: каждый push в `main` (или ручной запуск во вкладке Actions) собирает сайт
и публикует `dist/` на Pages. Один раз включить в репозитории: Settings → Pages → Source: **GitHub Actions**.

- `base` берётся из `BASE_PATH`, его подставляет `actions/configure-pages`: `/budini-coffee/` для
  `undemorbe.github.io/budini-coffee`, `/` для своего домена. Локально `BASE_PATH` не нужен.
- Роутер на `createWebHistory`, поэтому workflow копирует `index.html` в `404.html`: прямые ссылки вида
  `/budini-coffee/menu` открываются, а не дают 404 GitHub.
- Проверить сборку под подпутём локально:
  `BASE_PATH=/budini-coffee/ npm run build && BASE_PATH=/budini-coffee/ npm run preview`.

## Страницы

- `/` главная: 3D scroll-video (стакан Будини, кофейная воронка в фирменных разводах, зёрна, пар),
  бегущая строка, «Почему Будини», предзаказ «Будильник», хиты, кофейни.
- `/menu` меню: категории, фильтры (без кофеина, растительное молоко, холодное, новинки),
  шкала «бодрости», выбор размера в карточке.
- `/addresses` адреса: схема города, список кофеен, статус «открыто сейчас», карточка точки, «Заказать сюда».
- `/order` предзаказ «Будильник» отдельной страницей: как это работает, вопросы.
- `/bonus` бонусная программа: интерактивная карта на 10 чашек, уровни, вопросы.
- `/about` о нас: цифры, «От зерна до чашки», история, ценности.
- `/events` события: каппинги и мастер-классы с местами, заявка на своё событие.
- `/gift` подарочные сертификаты: сумма, дизайн, получатель, живое превью.
- `/careers` вакансии: условия, открытые позиции, отклик по почте.
- `/contacts` контакты: телефон, соцсети, форма с проверкой полей, частые вопросы.
- 404 «Тут ещё спят».

Header и footer общие для всех страниц.

## 3D scroll-video

Сделано по скиллу [scroll-video-website](https://github.com/musoyangrigor/scroll-video-website-skill):

1. `render.html` + `tools/render-scene.js`: детерминированная Three.js-сцена, `window.renderFrame(i)`.
2. Кадры (450 шт., 1600×900) сняты headless-браузером и собраны в `media/budini-hero.mp4` (15 с, 30 к/с).
   Камера идёт по одной сплайн-траектории (CatmullRom) с мягким разгоном и торможением.
3. Из видео извлечена WebP-последовательность `public/frames/frame_0001-0450.webp`
   (1280×720, качество 78, ~10 МБ). Разрешение снижено с 1600×900: при полной загрузке
   крупных кадров страница заметно тормозила.
4. `src/components/ScrollVideo.vue`: sticky-сцена с canvas, прогрессивная загрузка
   (первый кадр, каждый восьмой, остальные), плейхед на критически затухающей пружине, смешивание соседних кадров,
   окно заранее декодированных через `img.decode()` кадров вокруг плейхеда (нет подвисаний на декодировании при остановке; `ImageBitmap` не используется, он роняет вкладку в Chrome),
   `prefers-reduced-motion` (держит финальный кадр), очистка слушателей.

5. Для телефонов отдельная вертикальная версия той же сцены: `public/frames-m/` (225 кадров 540×960,
   ~3.9 МБ, `media/budini-hero-mobile.mp4`), камера с FOV 52 и сдвигом стакана вверх, чтобы его не
   закрывали плашки с текстом. `ScrollVideo` включает её на экранах уже 4:5 и переключает наборы на лету
   при повороте телефона; окно предзагрузки на телефоне меньше, чтобы экономить память.

6. Кофейные зёрна процедурные (`beanGeometry` в `tools/render-scene.js`): выпуклая спинка, плоская сторона,
   S-образная бороздка, вдавленная в геометрию, светлая серебристая плёнка на её дне, четыре варианта формы.
   Цвет в вертексах, материал `MeshPhysicalMaterial` с лёгким clearcoat (маслянистый блеск обжарки).

Важно: не ставить `overflow` на `html`/`body`. Тогда body становится scroll-контейнером и sticky-сцена
видео уезжает вместе со страницей. Горизонтальный вылет режется `overflow-x: clip` на `#app`.

Пересобрать кадры после правки сцены:

```bash
npm run dev  # затем открыть /render.html и снять кадры window.renderFrame(0..449)
# вертикальная версия: /render.html?w=540&h=960&fov=52&frames=225&shift=0.16
```

## Данные и архитектура

```
src/data/menuSource.js    сырые данные меню (формат будущего API, snake_case)
src/data/cafesSource.js   кофейни: адреса, id организаций и часы с Яндекс Карт
src/data/site.js          бренд, контакты (телефон, WhatsApp, Telegram, VK), навигация
src/domain/menu/models.js маппинг DTO → модели (Category, MenuItem, Volume, Tag), сезонность
src/domain/menu/getMenu.js use case: доступные категории, сезонная первой, фильтр по тегам
src/domain/cafes/models.js модель кофейни, «открыто сейчас», текст расписания
src/data/menu.js, cafes.js готовые модели для компонентов
```

Когда появится бэкенд, достаточно заменить `menuSource` / `cafesSource` ответом API того же формата.

**Сезонное меню.** У категории `is_seasonal`, `available_from`, `available_to` (даты включительно) и
`enabled`. Пока сезон идёт, категория выводится первой (меню, главная, предзаказ); вне периода или с
`enabled: false` скрыта. Код интерфейса менять не нужно.

**Открытые вопросы (TODO в коде):**
- цены осеннего меню не подтверждены: `AUTUMN_PRICES` в `menuSource.js` (временно 230 / 290 ₽);
- даты осеннего сезона (`available_from` / `available_to`);
- координаты трёх кофеен (карта работает и без них, по id организации).

Разделы «Бонусы», «События», «Сертификаты», «Вакансии» и предзаказ пока примеры будущей версии:
на них стоит плашка «Пример раздела», формы ничего не отправляют.

## GitHub Pages

1. Создать репозиторий и запушить проект в ветку `main`.
2. Settings → Pages → Source: **GitHub Actions**.
3. Workflow `.github/workflows/deploy.yml` прогонит тесты, соберёт сайт с `BASE_PATH=/<имя-репозитория>/`
   и опубликует его. Адрес: `https://<логин>.github.io/<имя-репозитория>/`.

Прямые ссылки вроде `/menu` работают через `404.html` (копия `index.html`, создаётся при сборке).
Локально проверить сборку как на Pages:

```bash
BASE_PATH=/budini-coffee/ npm run build && BASE_PATH=/budini-coffee/ npx vite preview
```
